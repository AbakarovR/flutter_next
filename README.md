# OilPro

Приложение для учёта работы автосервиса.

## Предпросмотр на iPhone без Android Studio

Веб-предпросмотр позволяет открыть адаптированный интерфейс приложения в Safari на iPhone.

1. Подключите компьютер и iPhone к одной сети Wi‑Fi.
2. В PowerShell перейдите в папку проекта и запустите сервер Flutter:

   ```powershell
   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 8080
   ```

3. На компьютере выполните `ipconfig` и найдите IPv4-адрес активного Wi‑Fi.
4. В Safari на iPhone откройте `http://АДРЕС-КОМПЬЮТЕРА:8080`, например `http://192.168.1.25:8080`.
5. Для завершения сервера нажмите `Ctrl+C` в PowerShell.

Если страница не открывается, проверьте, что устройства в одной сети, и разрешите Flutter доступ к частной сети в брандмауэре Windows.

Веб-предпросмотр удобен для проверки размеров, прокрутки и внешнего вида интерфейса. Данные в Safari хранятся отдельно от данных нативного приложения и не синхронизируются между устройствами.
